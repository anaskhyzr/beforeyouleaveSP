# Before You Leave

Before You Leave is a location-based checklist app that helps users prepare for departures by tracking what they need to remember before leaving home, work, school, or other recurring places.

Features:
- Build custom places with icons, GPS radius, and reminder times
- Track checklist items for each location
- Check items off before leaving
- Get departure notifications and quick actions
- Review forgotten-item history for recurring issues
- Use sample data only when you explicitly choose to load it

Getting started:
- Run `flutter pub get`
- Start the app with `flutter run`
- Open Settings to load sample data if you want a quick demo of the experience
